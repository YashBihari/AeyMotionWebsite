# Aeymotion development workflow

- Use the `beta` branch for website work and preview changes.
- Never commit, push, merge, or otherwise modify `main` unless the user explicitly instructs you to do so.
- Do not merge beta into main or change production hosting settings without separate explicit approval.
- Preserve unrelated changes. Show reviewable previews where available.
- The user requests confirmation before each new implementation or publishing step. Specific edits explicitly approved in the conversation may proceed; approval does not extend to later publishing steps.
